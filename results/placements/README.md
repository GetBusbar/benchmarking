# Benchmark placement records

These immutable plans record the AWS Price List observation, region, instance type,
Ubuntu image, frozen engine and source revision selected before each batch launched.
They contain no credentials. A planned entrant is not proof of a completed run;
completed measurement snapshots remain the evidence for results.

The quoted estimate covers the whole instance, configured gp3 disk and public IPv4.
It excludes taxes and variable transfer charges. Website performance-per-dollar
metrics use the separately disclosed common four-core reference price, not these
region-specific infrastructure bills.
